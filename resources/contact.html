This is a demonstration of a multi-threaded HTTP server built for educational purposes.

Server Details

  • Host: localhost (127.0.0.1)
  • Port: 8080 (configurable)
  • Protocol: HTTP/1.1
  • Thread Pool: 10 threads (configurable)

API Endpoints

  • GET / - Home page
  • GET /about.html - About page
  • GET /contact.html - This page
  • GET /[filename] - Download files
  • POST /upload - Upload JSON data

🧪 Testing the Server

Try these test scenarios:

  • Download text files: GET /sample.txt
  • Download images: GET /logo.png
  • Upload JSON: POST /upload with JSON body
  • Test security: GET /../etc/passwd (should return 403)
